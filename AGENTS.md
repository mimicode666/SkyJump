# SkyJump — инструкции проекта

## Цель и ограничения
- Основной продукт — SkyJump, простая Web First игра на Godot 4.6 / GDScript: персонажи из пользовательских GLB, автоматические прыжки по цветным платформам. Русский и английский интерфейс, лёгкая мультяшная графика. Не возвращать стиль PS2.
- Каждая новая игровая система должна работать в Godot 4 Web Export. Основная цель — браузер; нативный запуск служит вспомогательной проверкой.
- Использовать Compatibility / WebGL 2 и однопоточный экспорт. Не добавлять обязательные Thread, C#/.NET, нативные расширения, процессы ОС или платформенные API без рабочей Web реализации. Проверять поддержку новых зависимостей до внедрения.
- Игровые ресурсы — res://; сохранения при необходимости — user:// с учётом браузерного хранилища и недоступности сохранения. Не обращаться к путям Windows из игрового кода. Инструменты сборки могут быть платформенными.
- Звук, fullscreen и прочие browser APIs учитывать с ограничениями браузера; для нужных разрешений использовать действие пользователя. Поддерживать клавиатуру и сенсорное управление.
- Все ресурсы локальные. Без CDN, аналитики, облачных API, регистрации. Локальный сервер слушает только 127.0.0.1. Не публиковать игру и не создавать туннели без явного запроса.
- Исключение по запросу пользователя: интеграция SDK Яндекс Игр. При размещении на платформе разрешён её `/sdk.js` и штатные события/реклама SDK. На loopback и в native внешних запросов нет. Черновик: https://games.yandex.ru/console/application/619347#application-info-draft. Материалы карточки заполняются по запросу владельца; игру не загружать/публиковать автоматически.
- Исходные модели не изменять. Рабочие облегчённые копии сохраняют материалы, WebP и UV. Не усложнять MVP без задачи пользователя.

## Текущее состояние
- Во время тяги персонаж и джетпак вращаются вокруг общей вертикальной оси (4,6 рад/с × темп). Смещение крепления вращается вместе с героем без масштаба GLB; пауза останавливает вращение, после тяги герой плавно возвращается к исходному углу. Логический игрок и управление не вращаются.
- Шлейфы и их магазин удалены по запросу пользователя. Профиль v5 однократно возвращает цену купленных шлейфов (40/60/90/140), сохраняя монеты, персонажей, рекорды, звук и ×2. Начисление разработчику остаётся в его локальном профиле.
- Текущий баланс: радиус блинчика 0,78, промежутки 2,1–2,6; обычный прыжок 13,2 при гравитации 30, пружинка 22. Впереди генерируется 24 единицы маршрута; иногда добавляются боковые безопасные площадки. Темп игрока и движущихся платформ плавно растёт до ×1,4 от высоты и времени; траектория прыжка сохраняется.
- Девять персонажей с ценой в монетах: Пикачу/Яблочко/Пингвин — 0, Зайчик — 50, Клубнич Джунгариков — 75, Миньон — 100, Манье — 200, Кирби (kirby-blink-fixed.glb)/Синнаморол — 250. Последние двое моргают встроенными анимациями. Просмотр закрытого героя бесплатный, покупка отдельной кнопкой. Играть можно только доступным. Эмиль/Света/Мбаппе сняты с выбора и Web-сборки.
- Монета на каждой 5–8-й основной платформе; user://wallet.cfg хранит баланс, покупки, 10 лучших локальных забегов и срок ×2. Web дополнительно синхронно сохраняет профиль в localStorage через адаптер (ключ skyjump:<путь>), чтобы быстрая перезагрузка не теряла покупки до синхронизации IndexedDB. Старый баланс сохраняется. QA использует отдельные qa-*.cfg; очищать через Wallet.clear_profile(), включая зеркало.
- SDK: LoadingAPI.ready после готового кадра, GameplayAPI по состоянию, game_api_pause/resume + visibility/focus, отключение ввода/звука при рекламе. Только onRewarded с последующим завершением даёт ×2 на 600 секунд реального времени либо одно безопасное продолжение забега. Часы SDK serverTime при доступности; локальные — иначе. Отмена/недоступность не даёт награды; повторное падение обновляет тот же рекорд. На localhost реклама недоступна. Настоящий SDK в черновике ещё не проверен. Онлайн-лидерборд и облачные сохранения не подключены; текущая таблица личная. Поддерживаются ru/en. Язык SDK применяется до меню/Game Ready; без SDK русский. Fallback: be/kk/uk/uz → ru, остальные → en. Облачное хранилище Player не используется.
- Радиус области приземления: 0,78 + 0,14 стопа + 0,05 допуск; видимый размер платформ прежний.
- Платформы всегда непрозрачны: затухание при пересечении удалено. Только визуал персонажа сдвинут на 4 единицы вдоль оси взгляда к ортографической камере; экранные координаты и масштаб сохраняются, логический игрок/коллизии/монеты не смещаются. Материалы GLB не меняются.
- Выбор/магазин карт заменён непрерывным путешествием по максимальной высоте забега: Земля 0 м, дождь 500 м, снег 1100 м, над облаками 1800 м, закат 2800 м, ночь 4100 м, Луна 5800 м, галактики 8000 м. Переходы растянуты на 200 м и не откатываются при падении. Повтор/меню возвращают Землю. Зоны бесплатны; оформление не меняет RNG маршрута. В ночи/у Луны/галактиках новые синие платформы получают множитель скорости ×1,2/×1,35/×1,5. Магнит работает только при активном джетпаке.
- Профиль v4: прежние покупки карт возвращаются монетами один раз (50/75/100/150); version и новый баланс сохраняются вместе в user:// и Web-зеркало. Старые монеты, скины, рекорды и срок ×2 сохранены. В меню выключатель звука, настройка хранится в профиле.
- Баланс — общий верхний слой с вращающейся монетой и числом, не внутри списка персонажей. Портретная камера шириной 8,8; порог проигрыша camera_height − 7. Нижний край кадра на игровой плоскости расположен на 2 единицы выше этого порога, чтобы герой целиком исчезал до проигрыша; узкий экран расширяет обзор только вверх. Игровая камера следует camera_height без дополнительного Y-отставания, масштаб и боковые границы прежние. Границу падения не рисовать (ни линию, ни подсветку, ни текст). Подставки персонажей в меню молочно-белые и вдвое шире игровых. Не снижать разрешение 3D и качество сглаживания для телефона.
- Окружения — локальные меши/батчи: холмы, дождь, 72 падающие снежинки в одном MultiMesh, 64 звезды, приближающаяся Луна с кратерами, две спиральные галактики. Новых источников света нет; небольшие 64×64 покрытия/свечение генерируются и кэшируются локально. Цвета специальных платформ и обозначения сохранены.
- При отскоке меняется только дочерний artwork блинчика: упругое сжатие/расширение и тонкое кольцо; камень дрожит и осыпает крошки, пружинка распрямляется. Логический root, коллизии и монеты не смещаются. Фигурка больше не сжимается. Три коротких WAV воспроизводятся AudioStreamPlayer после кнопки старта, затихают при паузе/потере фокуса/рекламе; Web Sample без дополнительных потоков/аудиоэффектов.
- Управление A/D или стрелки, прыжок автоматический; Esc — пауза, R после падения — повтор. Мышь не управляет героем. На сенсорном экране первый палец задаёт направление последним горизонтальным сдвигом в любом месте, без возврата к центру/началу жеста. Пока палец удерживается, направление сохраняется; отпускание/отмена/пауза/потеря фокуса сбрасывают его. Порог 1,5 экранного пикселя отсекает дрожание, второй палец не перехватывает управление; касание на паузе исключено. Перед первым забегом после открытия — белая заставка с объяснением и кнопкой старта; повторные попытки без заставки.
- «Рекорды» выровнен по центру: один лучший результат за всё время, «Список лучших» и единственная строка «1 — Вы — метры». Старые сохранённые забеги не удаляются; общая таблица Яндекс Игр ещё не подключена. В меню увеличены монетка и число, игровой HUD прежнего размера. В портрете список персонажей занимает нижнюю часть экрана, превью уменьшено.
- SkyJump: мобильная портретная/альбомная раскладка без полос, прокручиваемое меню персонажей. Боковая скорость 7,4, ускорение 58; переход через видимые края сохраняет импульс. Бирюзовые платформы движутся, розовые с пружиной усиливают прыжок, красные с шипами завершают забег. Шипы только дополнительные, основной маршрут безопасен.
- Web: полный прогон и новые механики проверены в браузере, в том числе события мультитача и камень. Физический телефон ещё не проверялся. Подробности: game/WEB.md.

- У каждой синей платформы собственная постоянная базовая скорость 1,1–3,8 рад/с, умноженная на коэффициент зоны появления (до ×1,5) и общий темп. Уже появившиеся платформы не разгоняются при смене зоны. Амплитуда и границы прежние; отдельный motion_rng не меняет RNG маршрута.
- Джетпак появляется только на обычной основной платформе без монеты: первый после 22–30 платформ, затем интервал 36–52 с отсрочкой до подходящей платформы. pickup_rng отдельный. Подбирается автоматически (проверка отрезка без пересечения игрового поля при wrap); уже активную тягу повторный предмет не продлевает. Топливо 3,2 секунды игрового времени, скорость до 24, плавное окончание за последние 0,35 секунды. Около 700 м подъёма; горизонтальное управление и генерация продолжаются. Топливо и анимация стоят при паузе/рекламе/потере фокуса, сбрасываются при повторе/меню/проигрыше. Фигурки и GLB не меняются. При активной тяге монеты в радиусе 3,4 единицы подтягиваются со скоростью 40 единиц/с игрового времени; зачисление проходит через обычный кошелёк, включая ×2, без повторов. Магнит прекращается вместе с тягой и не действует через перенос на противоположный край. Справа под паузой — шкала топлива. Web-проверки включены в --journey-test, один герой.
## Экономный порядок работы
1. Начинать с этих инструкций и git status --short. Читать только нужные строки файлов по таблице и относящиеся к задаче изменения.
2. Не перечитывать весь репозиторий, историю чата, все README и старые отчёты для небольшой правки. Расширять поиск только при конкретной зависимости или ошибке.
3. Посторонние документы и их вспомогательные файлы не читать, не учитывать и не добавлять в Git. Игнорируемые каталоги, кэши, модели и бинарники не сканировать без необходимости задачи.
4. Делать минимальное законченное изменение. Без несвязанного рефакторинга, новых систем и повторной оптимизации моделей. Не привлекать субагентов без запроса.
5. Запускать проверки по изменению, не весь набор для правки текста. После успешной проверки не повторять её без причины. Для новой игровой системы нужен экспорт и проверка в браузере; если среда мешает — явно записать, что не проверено.
6. При изменении архитектуры, команд или статуса Web обновить соответствующую краткую документацию. AGENTS.md хранит правила и карту, а не журнал каждой задачи.

## Команды и версии
Команды из корня, PowerShell. Локальный движок: `.tools/godot/Godot_v4.6-stable_win64_console.exe` (ниже GODOT).
- Физика/генерация/камень: `& GODOT --headless --path game --script res://tests/platform_rules_test.gd` — 80 000 переходов при темпе ×1 и ×1,4.
- Интеграция/модели/UI: `& GODOT --path game -- --self-test` — реальный игровой прогон, снимки в qa/. Не запускать headless для проверки внешнего вида.
- Камера без полного прогона моделей: `& GODOT --path game -- --camera-test`; отдельный qa-camera-wallet.cfg. Путешествие/отскок/миграция: `--journey-test`, отдельный qa-journey-wallet.cfg. В Web debug передать выбранный аргумент вместо `--self-test`; дополнительный `--journey-tour` показывает QA-кнопку перебора зон после теста. В release её нет.
- SDK без сети: `node --test game/tests/yandex_bridge_test.mjs`. Архив черновика: `powershell -NoProfile -ExecutionPolicy Bypass -File ./build-yandex.ps1` → build/SkyJump-Yandex.zip, без публикации. Не подменять результатами имитации проверку настоящей рекламы.
- Редактор: `Открыть проект Godot.cmd`; нативный запуск разработчика: `powershell -File start-game.ps1`.
- Браузерный запуск готовой сборки: `Играть в браузере.cmd` → start-web-game.ps1 → server-game.mjs, только http://127.0.0.1:4174/ . Сборка лежит в build/web/; после изменения исходников её нужно пересобрать.
- Web: команды и проверка в game/WEB.md. Снимки и результаты сборки не коммитить.
- Публичный репозиторий: https://github.com/mimicode666/SkyJump ; GLB/PNG/WebP в Git LFS. Инструменты .tools/ и кэши не входят в Git.
- Перед сохранением проверять diff и добавлять конкретные файлы задачи. Не менять чужие правки. В финале кратко: результат, проверка и существенные ограничения.

Основания: [AGENTS.md в Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [Godot 4.6 Web Export](https://docs.godotengine.org/en/4.6/tutorials/export/exporting_for_web.html).

## Готовая игра и упаковка
- Игроки скачивают только последний релиз: Windows x64 ZIP или Linux x64 TAR.GZ; Godot/Node не нужны. GitHub Source code — исходники с Git LFS.
- build-portable.ps1 экспортирует текущий Web и собирает автономные локальные запускатели (Go); версия в package.json, результат build/releases/. Инструменты сборки платформенные, игра по-прежнему Web First.
- tools/launcher/ — сервер 127.0.0.1:4174, MIME, открытие браузера и ошибки архива/порта. CI launcher.yml проверяет Windows/Linux. Изменение запускателя не требует полного прогона моделей.
- Текущая задача касается полной актуальной версии; старые сборки не восстанавливать и не обслуживать.
