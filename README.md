# SkyJump

Простая Web First игра на Godot 4.6: выбирайте персонажа и прыгайте по облачным платформам. Русский интерфейс, клавиатура и сенсорные кнопки, шесть персонажей, два фона, монеты с локальным сохранением.

## Запуск

- **`Играть в браузере.cmd`** — основная версия, http://127.0.0.1:4174/ . Нужны Node.js и готовая папка `build/web/`. Сервер доступен только на этом компьютере.
- `Играть.cmd` — вспомогательный нативный запуск.
- `Открыть проект Godot.cmd` — редактор проекта.

Прыжки автоматические; A / D, стрелки или экранные кнопки — движение. Esc — пауза. Монеты сохраняются в хранилище текущего браузера; при его очистке баланс теряется. Магазина пока нет.

Все ресурсы локальные, публикации и внешних сервисов нет. После изменения исходников браузерную сборку нужно обновить: команды в [game/WEB.md](game/WEB.md). Описание игры — [game/README.md](game/README.md), карта кода и правила работы — [AGENTS.md](AGENTS.md).

## Сохранённые версии

Приватный репозиторий: https://github.com/mimicode666/player-two-chibi-jump . GLB, PNG и WebP хранятся через Git LFS; после клонирования нужен `git lfs pull`.

- `mvp-v0.1.0` — первая игра.
- `mvp-v0.2.0` — случайный маршрут и разрушаемый камень.
- `mvp-v0.3.0` — SkyJump, мобильная раскладка, меню, переход через края, движущиеся платформы, пружины и шипы.
- `mvp-v0.4.0` — новый состав персонажей и моргающий Кирби, монеты с сохранением, постепенное ускорение, меньшие платформы, монетка в интерфейсе и более близкая мобильная камера.

Исходники моделей сохранены в `game/source-models/`; игровые копии — в `game/assets/models/`. Старый сайт удалён из текущей версии, предыдущие сохранения Git доступны.

Godot, шаблоны экспорта, `node_modules`, сборки, кэши и снимки проверок не входят в Git. Для нового компьютера нужен [Godot 4.6 stable](https://godotengine.org/download/archive/4.6-stable/) в `.tools/godot` и соответствующие Web Export Templates. Node-зависимости нужны только для подготовки моделей, не для игры.
