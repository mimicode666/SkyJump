SkyJump — готовая игра для браузера

Распакуйте архив целиком в обычную папку. Не запускайте файлы внутри архиватора.
Godot, Node.js, Go и подключение к интернету для игры не нужны.
Нужен современный браузер с WebGL 2 и включённым аппаратным ускорением.

Windows 10/11, x64
  Откройте SkyJump.exe. Игра откроется в браузере автоматически.

Linux, x64
  Откройте терминал в распакованной папке и выполните:
    bash ./play-skyjump.sh
  Скрипт выставит право запуска и откроет игру в браузере.
  Если браузер не открылся, введите адрес из окна запуска вручную.

Адрес: http://127.0.0.1:4174/
Оставьте окно запуска открытым. Чтобы остановить игру, закройте его или нажмите Ctrl+C.
Если порт занят старой версией или другим локальным сервером, сначала закройте его.
Сервер доступен только на этом компьютере, без сетевой публикации.
Не открывайте web/index.html двойным щелчком: игре нужен локальный сервер.

Управление
  A / D или стрелки — влево / вправо. Прыжки автоматические.
  Можно удерживать мышь или палец в левой / правой половине экрана.
  Esc — пауза, R после падения — повтор.

Монеты, покупки и рекорд сохраняются в этом браузере, по этому адресу.
Для сохранения прогресса используйте тот же браузер и обычное, не приватное окно.
Удаление данных браузера удаляет прогресс. Облачного переноса пока нет.
Локальная версия работает без рекламы; рекламные бонусы здесь недоступны.

Последняя версия и исходники: https://github.com/mimicode666/SkyJump
