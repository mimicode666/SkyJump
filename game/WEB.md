# SkyJump: Web

Браузер — основная платформа. Godot 4.6 / GDScript, Compatibility / WebGL 2, однопоточный экспорт без нативных расширений. [Ограничения Godot Web](https://docs.godotengine.org/en/4.6/tutorials/export/exporting_for_web.html).

## Запуск и сохранения

[Готовые архивы](https://github.com/mimicode666/SkyJump/releases/latest) включают Web-экспорт и автономный локальный сервер. Для игроков Godot не нужен. Команды сборки — [README.md](README.md).

Адрес `http://127.0.0.1:4174/` сохраняется между версиями. `user://wallet.cfg` зеркалируется в localStorage (`skyjump:<путь>`), чтобы быстрое закрытие вкладки не теряло покупки. Другой браузер, порт или приватное окно имеют отдельное хранилище. При отказе обоих хранилищ прогресс временный.

Локальная игра не обращается к внешней сети. SDK Яндекс Игр включается только на платформе; настоящий SDK пока не проверен в черновике. Статус — [YANDEX.md](YANDEX.md).

## Требования к изменениям

- Локальные `res://` ресурсы; никакого обязательного CDN, Thread, C# или OS API в игре.
- Звук и fullscreen — после действия пользователя. Web Sample без дополнительных потоков и AudioEffects.
- Клавиатура, мышь и сенсорные половины экрана. При паузе/потере фокуса сбрасываются касания и звук.
- Камера адаптируется к портрету без снижения чёткости. Граница падения не рисуется.
- Нативный тест не заменяет испытание в браузере.

## Проверка игрового изменения

Экспортируйте debug Web в `build/web/check.html`. В HTML замените `"args":[]` на `"args":["--","--journey-test"]` либо нужный аргумент ниже. Открывайте страницу через локальный сервер. В обычном release аргументы пустые.

| Аргумент | Область проверки |
| --- | --- |
| `--camera-test` | Пять соотношений сторон, один персонаж, падение, повтор и пауза |
| `--journey-test` | Зоны, отскок, звук, миграция профиля, сброс окружения |
| `--self-test` | Персонажи, покупки, рекорды, управление и полный игровой прогон |

К `--journey-test` можно добавить `--journey-tour` для осмотра зон. QA использует отдельные `qa-*.cfg`; игровой профиль не сбрасывать. При проверке сохранений перезагрузить страницу и сравнить значения. Проверять консоль и внешние запросы.

Игра проверена во встроенном Chromium на Windows: путешествие, платформы, меню, управление, камера и сохранения. Физический телефон, Safari/Firefox и слабые устройства ещё не проверены. Результаты — [ПРОВЕРКА.md](ПРОВЕРКА.md).
