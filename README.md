# SkyJump

Прыгай по платформам от зелёных холмов к Луне и далёким галактикам. Собирай монеты, открывай персонажей и улучшай рекорд.

## Скачать и играть

**[Готовая игра для Windows и Linux →](https://github.com/mimicode666/SkyJump/releases/latest)**

| Система | Архив | Запуск после распаковки |
| --- | --- | --- |
| Windows 10/11, x64 | `SkyJump-…-windows-x64.zip` | Открыть `SkyJump.exe` |
| Linux, x64 | `SkyJump-…-linux-x64.tar.gz` | В терминале папки: `bash ./play-skyjump.sh` |

Распакуйте **весь архив**. Игра откроется в браузере; Godot и другие программы устанавливать не нужно. Нужен браузер с WebGL 2. После скачивания можно играть без интернета.

Окно запускателя должно оставаться открытым. Если браузер не открылся автоматически, перейдите на **http://127.0.0.1:4174/**. Закройте окно запускателя, чтобы остановить сервер. Он доступен только на вашем компьютере.

**`Code → Download ZIP` и `Source code` содержат исходники, а не готовую игру.** Для игры скачивайте архив своей системы из Releases. Не открывайте `index.html` напрямую.

## Управление

- **A / D, ← / →** — движение. Прыжки автоматические.
- **Сенсорный экран:** коснитесь любого места и сдвигайте палец влево или вправо. Обратный сдвиг сразу меняет направление — возвращаться к центру или началу жеста не нужно. Пока палец удерживается, герой продолжает движение; отпустите палец, чтобы остановиться.
- На ПК герой управляется клавиатурой. Мышь используется для меню.
- Кнопка паузы или **Esc** — пауза. **R** после падения — повтор.

Перед первым забегом появляется краткая подсказка. Сенсорное управление работает на телефонах, планшетах и компьютерах с сенсорным экраном.

Девять персонажей, платформы с разной скоростью движения, пружины, шипы и редкий джетпак с магнитом для монет. Восемь окружений плавно сменяют друг друга: от земли, дождя и снега до далёких галактик. Монеты, покупки и личный рекорд сохраняются в текущем браузере. Локальная версия без рекламы; общая таблица рекордов и облачные сохранения пока не подключены.

Интерфейс доступен на русском и английском. Локально по умолчанию используется русский; английский можно открыть по адресу `http://127.0.0.1:4174/?lang=en`. На Яндекс Играх язык определяется через SDK до появления меню.
