# PLAYER TWO

## Сохранённые версии

Проект хранится в приватном Git-репозитории. GLB, PNG и WebP используют Git LFS: при восстановлении проекта нужны `git clone` и `git lfs pull`. Первая рабочая версия игры отмечена тегом `mvp-v0.1.0`.

Версия `mvp-v0.2.0`: более разбросанные платформы, увеличенные случайные промежутки и каменные платформы, которые ломаются после второго приземления.

В историю входят исходники, оригинальные и облегчённые модели, текстуры и локальные библиотеки сайта. Папка `.tools` с Godot, кэши, журналы и `node_modules` исключены. На новом компьютере скачайте Godot 4.6 по ссылке в `game/README.md` и распакуйте в `.tools/godot`, затем запустите `Играть.cmd`.

## Игра — новый MVP

Запустите **`Играть.cmd`** для локальной игры на Godot 4.6. Выберите Эмиля или Свету, затем нажмите «Прыгать!». A / D или стрелки — движение; прыжок автоматический; Esc — пауза. Полное описание текущего небольшого MVP: `game/README.md`. Для редактирования: `Открыть проект Godot.cmd`.

Ниже — документация прежнего веб-просмотра. В нём выбор персонажей теперь использует новые чиби-модели (`dist/models/emil-chibi.glb` и `sveta-chibi.glb`); прежние бюсты сохранены как отдельные файлы.

Локальный сайт с двумя настоящими GLB-бюстами. Никаких внешних запросов, CDN, облачных сервисов или аналитики.

## Запуск

Дважды нажмите `Запустить сайт.cmd`: сервер запустится в фоне, а сайт откроется в браузере. Повторный запуск открывает уже работающий сайт. После перезагрузки компьютера нажмите файл снова. Адрес: http://127.0.0.1:4173. Для запуска с видимым окном сервера выполните `node server.mjs` из папки проекта. Сервер слушает только 127.0.0.1; с других компьютеров и телефонов в сети он недоступен. Мобильная компоновка работает при узком окне; на отдельном телефоне нужен собственный локальный сервер с копией проекта. При ручном запуске для остановки нажмите Ctrl+C в окне сервера.

После установки требуется только Node.js. Все используемые библиотеки находятся в `dist/vendor`, шрифт — системный (Segoe UI / Arial), модели — в `dist/models`. Интернет для запуска не нужен. `node_modules` не используется сервером или сайтом.

## Модели и управление

- `meshy_очки.glb` → Эмиль (`dist/models/emil.glb`).
- `meshy_1789859225224.glb` → Света (`dist/models/sveta.glb`).
- Модели скопированы без изменений. Встроенные WebP, материалы, нормали и KHR_texture_transform обрабатываются GLTFLoader.
- Размеры и центр вычисляются по мировым границам; масштаб применяется к контейнеру сцены. Геометрия и материалы не переписываются.
- Перетаскивание / один палец — вращение; колесо / щипок — масштаб. Два пальца также позволяют поворачивать модель. Сдвиг отключён.
- При фокусе на просмотре: стрелки — вращение, `+` / `−` — масштаб, `0` — сброс. Escape возвращает главное меню.
- Загруженные модели и текущие запросы хранятся в памяти: повторного запроса GLB при переключении нет. После обновления страницы кэш создаётся заново.

Исходный код: `dist/index.html`, `dist/style.css`, `dist/app.js`. Статическая папка сайта: `dist`. Сервер: `server.mjs`. Three.js 0.180.0 (MIT); лицензия в `dist/vendor/LICENSE`.
